## About the Project

NEMO WEB PLAYER is a browser-based streaming interface
designed to play HLS (M3U8) video streams directly
from a user-provided URL.

The application provides a simple dark-themed interface
without requiring additional software installation.

## Features

- Browser-based video player
- M3U8 stream URL input
- Integrated playback controls
- Fullscreen video controls
- Dark-themed user interface
- Web-based access

## How to Use

1. Open the web player.
2. Enter an authorized M3U8 stream URL.
3. Click the play button.
4. Enjoy the content directly in your browser.

Playback depends on browser compatibility and
stream server configuration.
